# Facial Recognition Model

A privacy-first, local command-line tool that enrolls consenting people from
reference photos and identifies them in group images.

> [!IMPORTANT]
> This project is for consent-based personal and educational use. Do not use it
> for surveillance or decisions affecting access, employment, housing, credit,
> healthcare, or law enforcement.

The implementation uses OpenCV's YuNet face detector and SFace embedding model.
Photos and biometric embeddings stay on your computer.

## Status

Initial development is in progress.
